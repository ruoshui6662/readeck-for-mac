# 仓库结构与本机归档

- `ReadeckMac/Sources/`：应用源码与随应用发布的资源。
- `ReadeckMac/Tests/`：自动化测试和本地模拟服务。
- `ReadeckMac/scripts/`：本地构建脚本。
- `ReadeckMac/README.md`：功能、运行及同步行为说明。
- `LICENSE`：本客户端代码许可证；第三方资源许可单独保留。

以下目录留在本机，默认不纳入仓库：`archive/`（旧安装包及实验归档）、`demos/`（设计演示）、`readeck-upstream/`（独立上游源码检出）、`.work/` 和 `ReadeckMac/.work/`（本机验证构建），以及构建缓存、旧研究记录和设计截图。旧安装包位于 `archive/legacy-builds/`，当前 `ReadeckMac/dist/` 保留在原处。项目不会自动读取归档。

`.gitignore` 定义默认公开范围，不是隐私安全保证。首次提交前仍应检查候选文件、测试样本、第三方授权与历史记录，并确认没有个人地址、凭据、缓存正文、截图或其他不应公开的资料。历史文档未默认公开，因为其中可能包含本机路径、网络地址或实验链接。

含用户提供的实站链接或依赖私有本机网页归档的实站验证测试被排除在公开范围之外，仍保留在本机供后续验证；其余测试使用本机生成的模拟数据。旧版详细开发说明存于本机 `archive/legacy-docs/`，其中引用的历史记录未纳入公开仓库。

## 发布前仍需人工确认

- 客户端采用 AGPL-3.0-only；如有从其他项目直接复制或改写的代码，仍应核对来源、许可证和必要署名。Readeck 上游包含 AGPL-3.0-only 代码；API 兼容不代表代码的来源已经核实。
- 内置六张作品图片与清单中的 SHA-256 值一致；清单记录了馆方公共领域标记。发布前应重新检查每件作品页面及适用地区的权利状态：API 数据的 CC0 声明不意味着接口上的所有图片自动可自由使用。馆方 API 说明：<https://api.artic.edu/docs/>。
- 首次发布前逐个审阅 Git 实际暂存清单，不要使用 `git add -f` 强制加入被排除的本机归档、个人截图、数据或实站样本。扫描只能降低遗漏概率，不能证明没有隐私信息。
